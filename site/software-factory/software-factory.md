# Software Factory
{: .no_toc }

A [software factory]({{ site.baseurl }}/software-factory/reference/glossary/#software-factory) is coding agents that
work on their own toward a desired outcome, with a built-in validation loop that checks their output against what done
means and feeds findings back.
{: .fs-6 .fw-300 }
