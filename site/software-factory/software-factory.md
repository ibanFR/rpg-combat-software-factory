# Software Factory
{: .no_toc }

The software factory is the set of coding agents, instructions, skills, and workflows that turn issues into tested,
reviewed code in this repository.
{: .fs-6 .fw-300 }

This section is organized using the [Diataxis](https://diataxis.fr/) framework so you can quickly find the right
document type for the task at hand: Tutorials for learning by doing, How-to Guides for goal-oriented tasks, Reference
for facts and checklists, and Explanation for concepts and rationale.
